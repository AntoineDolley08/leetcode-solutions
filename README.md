# LeetCode Solutions

![Python](https://img.shields.io/badge/language-Python-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/license-MIT-green)

My Python solutions to LeetCode problems, organized by pattern/topic. Each file includes the problem statement, one or more solutions with the reasoning behind them, and time/space complexity analysis.

## Structure

Solutions are grouped by topic, following the [NeetCode 150](https://neetcode.io/practice) roadmap:

```
├── Arrays & Hashing
├── Two Pointers
├── Sliding Window
├── Stack
├── Binary Search
└── Linked Lists
```
